# ToolsQube

Run: `npm install` then `npm run dev` (http://localhost:4321)

## Aluth tool ekak danna
1. `public/scripts/my-tool.js` hadanna (audio-splitter.js eka example ekak widihata balanna).
   Tool eka `document.getElementById("tool")` athule render karanna.
2. `src/data/tools.js` eke `tools` list ekata object ekak add karanna.
3. Aluth category ekak nam `categories` list ekatath add karanna.
4. `git add . && git commit -m "add my-tool" && git push`

Deploy karanna kalin `astro.config.mjs` eke `site` eka real domain ekata wenas karanna.
